## Homebrew 6.0.0 주요 변경사항 한눈에 보기

Homebrew 메인테이너 Mike McQuaid는 2026년 6월 11일 **Homebrew 6.0.0**을 공식 발표했다. 이번 릴리스는 macOS를 넘어 Linux, Windows(WSL, winget)를 포함하는 '모든 곳의 패키지 관리자'로서의 정체성을 한층 강화하는 동시에, 공급망 보안 위협에 대응하는 여러 강화책을 담았다.

## 1. Tap Trust — 공급망 보안의 핵심

가장 주목할 변경은 **tap trust 메커니즘** 도입이다. 기존에는 `brew tap` 명령으로 서드파티 저장소를 등록하면 해당 저장소의 스크립트가 제한 없이 실행될 수 있었다. 6.0.0부터는 tap을 명시적으로 신뢰(trust)해야만 설치가 진행된다.

Homebrew 팀은 다른 패키지 관리자들이 겪고 있는 공급망 보안 문제를 인지하고 있다며, 새 **공급망 보안 문서**도 함께 공개했다. 기존 보호 장치(macOS 샌드박스, 모든 변경 사항에 대한 인간 검토, 환경 필터링, 패키지 관리자 = Homebrew 유지보수자 방침)에 더해 Linux 샌드박스와 민감한 위치 접근 차단이 추가됐다.

<div class="article-callout__icon">💡</div>
<div class="article-callout__body"><strong>Brewfile에서 tap 신뢰 설정</strong><br>서드파티 저장소를 Brewfile에서 사용하는 경우, <code>brew trust</code> 명령을 실행해 해당 tap을 명시적으로 신뢰해야 한다. CI 환경에서는 <code>brew tap --force-auto-update</code>가 아닌 신뢰 기반 플로우를 사용하도록 워크플로를 업데이트하는 것이 권장된다.</div>
</div>

## 2. Linux Bubblewrap 샌드박스 기본 활성화

이전까지 Linux에서는 빌드·테스트·설치 훅 단계가 샌드박스 없이 실행됐다. 6.0.0부터는 **Linux Bubblewrap 샌드박스**가 기본 활성화돼 macOS와 동일한 수준의 격리 환경이 제공된다. 이는:

- 포뮬라 빌드·테스트·postinstall 단계를 격리된 환경에서 실행
- 호스트 Ubuntu CI에 Bubblewrap 자동 설치
- Syntax-only 작업에는 샌드박스 셋업 생략으로 성능 최적화

## 3. 새 내부 JSON API — 기본값 전환

Homebrew 5.0.0에서 opt-in 방식으로 도입됐던 **내부 JSON API**가 6.0.0부터 기본값으로 전환됐다. 이 API는 모든 Homebrew 메타데이터를 단일 다운로드로 통합한다.

- `brew update`가 더 빠르고 네트워크 요청 횟수가 줄어듦
- `brew leaves` 명령이 약 **30% 빨라짐**
- 병렬 bottle tab 가져오기로 `brew upgrade` 속도 향상
- Ruby 라이브러리 스타트업 로딩 최적화

기존에 `HOMEBREW_USE_INTERNAL_API` 환경 변수를 사용하던 경우 해당 변수가 deprecated됐으므로 제거해야 한다.

## 4. macOS 27 (Golden Gate) 초기 지원

6.0.0은 Apple의 다음 macOS 버전인 **macOS 27 Golden Gate**에 대한 초기 지원을 추가했다. 한편 macOS 27은 Intel 프로세서 지원을 완전히 종료하기 때문에, Homebrew도 이에 따른 단계적 Intel 지원 종료 로드맵을 발표했다.

| 시점 | Intel x86_64 macOS 상태 |
|------|------------------------|
| 2026년 9월 | Tier 3 격하 — CI 지원 없음, 새 binary package 미빌드 |
| 2027년 9월 | 지원 완전 종료, 관련 코드 전량 삭제 |

M5 및 M5 Pro/Max CPU 인식 지원도 이번 릴리스에 포함됐다.

## 5. brew bundle 대폭 개선

`brew bundle`이 이번 릴리스에서 크게 강화됐다:

- **병렬 실행** 지원으로 설치 속도 향상
- npm, krew(kubectl 플러그인) 확장 지원
- macOS: App Store 앱 관리
- Linux: Flatpak 패키지 지원
- Windows(WSL): winget 패키지 지원

## 업그레이드 방법

```bash
brew update
brew upgrade
brew --version  # Homebrew 6.0.0 확인
```

서드파티 tap을 사용하는 경우, 새 tap trust 메커니즘에 따라 tap을 명시적으로 신뢰해야 할 수 있다. `HOMEBREW_USE_INTERNAL_API` 환경 변수가 설정돼 있다면 제거하자.
