## IPO 직후 단행된 역대급 딜

2026년 6월 12일 나스닥에 상장하며 시가총액 2조 달러(약 2,750조 원)를 돌파한 SpaceX가 불과 나흘 만에 AI 코딩 시장 진출을 위한 대형 카드를 꺼내 들었다. SpaceX는 6월 16일 자회사 X67 Inc.를 통해 Cursor 개발사 애니스피어를 600억 달러 규모의 전액 주식 교환 방식으로 인수하는 합병 계약에 서명했다고 SEC에 신고했다.

계약 구조상 애니스피어 주주들은 보유한 보통주·우선주 전량을 SpaceX 클래스 A 주식으로 교환받는다. 주식 교환 비율은 계약 종결 직전 7거래일 거래량 가중 평균 주가(VWAP)를 기준으로 산정된다. 계약이 특정 사유로 종결되지 않을 경우 SpaceX는 100억 달러의 위약금을 지불하며, 반독점 규제로 거래가 무산되면 별도의 규제 위약금 40억 달러를 부담한다.

## Cursor는 왜 600억 달러짜리인가?

2022년 샌프란시스코에서 창업한 애니스피어는 AI 코딩 에이전트 Cursor를 개발했다. Cursor는 코드 자동완성을 넘어 자율적으로 코드를 작성·테스트·배포하는 '에이전틱 코딩' 분야에서 OpenAI의 Codex, Anthropic의 Claude Code와 함께 시장을 3분하는 선두주자로 자리매김했다.

로이터가 6월 초 입수한 회사 데이터에 따르면 Cursor의 연간 B2B 매출은 약 26억 달러에 달하며, 엔터프라이즈 영업은 빠른 속도로 성장 중이다. Fortune 500 기업 절반 이상이 Cursor를 사용하고 있으며, a16z·Thrive·Nvidia·구글 등 실리콘밸리 정상급 VC들이 투자했다. 올해 초에는 자체 모델 'Composer 2.5'를 선보이며 코딩 에이전트 시장에서 모델 경쟁력도 확보하고 있다.

## xAI + Cursor = AI 코딩 시장 최강자?

SpaceX는 2026년 2월 일론 머스크의 AI 연구소 xAI를 흡수합병하면서 Grok 챗봇과 100만 H100급 GPU를 보유한 콜로서스(Colossus) 슈퍼컴퓨터를 산하에 편입했다. Cursor 인수의 핵심 시너지는 바로 이 컴퓨팅 인프라에 있다.

애니스피어는 올해 4월 SpaceX와의 제휴 발표 당시 "자체 모델 훈련을 더 크게 확장하고 싶었지만 컴퓨팅이 병목이었다"며 "콜로서스 인프라를 활용해 Composer 모델 지능을 대폭 높일 것"이라고 밝혔다. 실제로 이번 딜은 AI 코딩 분야에서 Anthropic(Claude Code)과 OpenAI(Codex)에 뒤처진 xAI가 단번에 상위권으로 도약하는 발판이 될 수 있다.

## 엔터프라이즈 고객에겐 무엇이 달라지나?

InfoWorld 등 업계 매체들은 Cursor의 기존 엔터프라이즈 계약이 "모델 중립성"을 보장하고 있어 인수 이후 xAI 모델로의 강제 전환 가능성에 우려를 표명했다. Cursor는 현재 고객 데이터를 LLM 훈련에 사용하지 않겠다는 계약상 약속과 함께, 모델 공급사 변경 시 90일 사전 통보 조항을 두고 있다. SpaceX가 이를 어떻게 처리하느냐가 기업 고객 유지의 변수가 될 전망이다.

## AI 코딩 시장 경쟁 구도 변화

| 플레이어 | 제품 | 모델 | 컴퓨팅 기반 |
|---|---|---|---|
| Anthropic | Claude Code | Claude Fable 5 | AWS (자체 계약) |
| OpenAI | Codex Agent | GPT-5.4 | Azure / 자체 |
| SpaceX(예정) | Cursor + xAI | Grok 4.3 / Composer | 콜로서스 슈퍼컴퓨터 |
| Microsoft | GitHub Copilot | GPT-5.4 / Claude | Azure |

이번 인수는 AI 코딩 시장이 단순 도구 경쟁에서 **컴퓨팅·모델·에이전트를 수직 통합한 플랫폼 경쟁**으로 전환됨을 시사한다. SpaceX의 거대한 컴퓨팅 자원과 Cursor의 막대한 개발자 사용자 기반이 결합되면, OpenAI·Anthropic 중심의 현 판도가 크게 흔들릴 수 있다.
