## "챗은 죽었다" — 내부에서 나온 선언

OpenAI 내부에서 울려 퍼진 문장이다. 파이낸셜 타임스는 익명의 시니어 OpenAI 직원 발언을 인용해 회사가 ChatGPT를 대화형 챗봇에서 자율 에이전트 플랫폼으로 전환하는 작업이 마무리 단계에 접어들었다고 보도했다. 단순한 Q&A 인터페이스가 아니라, 사용자를 대신해 복잡한 작업을 수행하는 **자율 에이전트 허브**가 목표다.

수 주 안에 ChatGPT 웹사이트와 모바일 앱이 전면 개편된다. 변화의 핵심은 세 가지다.

1. **Codex 코딩 에이전트 전면화** — 코드를 작성하고, 테스트하고, PR까지 제출하는 Codex가 메인 화면으로 올라온다.
2. **이미지 생성·서드파티 앱 연동** — 단일 인터페이스에서 여러 능력을 동시에 활용할 수 있도록 통합된다.
3. **무료 사용자 유료 전환 경로 강화** — 무료 사용자가 Codex 같은 유료 기능을 자연스럽게 탐색하도록 유도하는 UX 설계.

## 왜 지금인가 — IPO와 Anthropic 압박

이 전략 전환에는 두 가지 강력한 동인이 있다.

**첫째, IPO.** OpenAI는 2026년 5월 Goldman Sachs와 Morgan Stanley를 주관사로 지정하며 IPO 추진을 공식화했다. 여름이 끝나기 전 상장이 목표다. 투자자들에게 단순한 "AI 챗봇 회사"가 아닌 **플랫폼 기업**으로 자리매김하려면 Codex 같은 유료 제품으로 사용자를 자연스럽게 끌어들이는 수익 구조가 필요하다.

**둘째, Anthropic.** Anthropic은 2026년 6월 1일 $65B 투자 라운드를 마무리하며 기업 가치를 $965B(약 1조 달러)까지 끌어올렸다. 연간 수익 런레이트는 $47B에 달한다. 특히 엔터프라이즈 AI 코딩 시장에서 Claude Code를 앞세워 OpenAI를 앞서 나가고 있다는 평가가 나온다. OpenAI의 슈퍼앱 피벗은 이 격차를 좁히기 위한 정면 대응이다.

<div class="article-callout tip">
<strong>개발자 인사이트:</strong> OpenAI가 Codex를 슈퍼앱의 중심으로 삼는다는 것은 코딩 에이전트 경쟁이 단순한 모델 성능 싸움에서 <em>플랫폼 생태계 싸움</em>으로 넘어간다는 신호다. Claude Code, GitHub Copilot과의 경쟁 구도가 더욱 격화될 전망이다.

## 게임 체인저인가, 포장 변경인가

월스트리트 저널은 이번 변화가 "새로운 AI 능력이나 기능의 근본적 변화라기보다 패키징과 수익 전략"이라고 평가했다. OpenAI는 Sora 같은 사이드 프로젝트를 포기하고 핵심 제품에 집중하는 방향으로 전략을 좁혔다.

| 구분 | 기존 ChatGPT | 슈퍼앱 ChatGPT |
|------|------------|--------------|
| 중심 기능 | 대화형 Q&A | 자율 에이전트 작업 수행 |
| 핵심 제품 | 채팅 | Codex + 이미지 생성 + 서드파티 |
| 수익 모델 | 구독 | 구독 + 에이전트 사용량 과금 |
| 경쟁 포지션 | AI 챗봇 1위 | AI 플랫폼 생태계 |

## 전망

AI 업계는 지금 챗봇에서 에이전트로 패러다임이 이동하는 변곡점에 있다. OpenAI의 슈퍼앱 전환은 이 트렌드를 가장 대중적인 AI 제품에서 공식화하는 사건이다. Codex, Claude Code, GitHub Copilot이 맞붙는 코딩 에이전트 전쟁은 이제 단순한 기능 경쟁이 아니라 개발자 생태계 전체를 장악하기 위한 플랫폼 전쟁으로 격상됐다. 누가 개발자의 기본 작업 환경이 되느냐가 다음 AI 사이클의 승패를 가를 것이다.
